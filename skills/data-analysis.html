Professional Skill
Data Analysis

Using structured data to identify trends, exceptions, patterns and opportunities for improvement.

Practical Application

Supports evidence-based decisions in stores, inventory and purchase activities.

Key Areas

Common techniques include Excel analysis, pivot tables, lookup functions, consumption trends, exception reports and classification analysis.

Relevant KPIs

Useful measures include consumption trends, variance, turnover, ageing and forecast-versus-actual performance.
